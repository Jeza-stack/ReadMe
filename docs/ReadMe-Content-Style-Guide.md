# ReadMe Content Style Guide
**Status:** Draft for JB review (Phase 1B) · Applies to every published page, whether written by Dr. Basha, drafted with AI, or migrated.

## 1. Voice & language
- **UK English** throughout (organise, colour, programme; -ise endings).
- Tone: academically rigorous, warm, direct. Write as a lecturer speaking to a capable student — never condescending, never breathless.
- Second person for instruction ("you will analyse…"), first person plural for shared reasoning ("we can read this line as…").
- Sentences average ≤ 22 words. One idea per paragraph. No filler openers ("It is important to note that…").
- Define every technical/literary term at first use, and link it to the glossary.

## 2. Page structure (Four-Question Framework — mandatory)
Every page, in order:
1. **Why am I here?** — 1–2 sentence context opener (week/course/level relevance)
2. **What should I learn?** — the lesson body
3. **Why does it matter?** — explicit link to assignment, exam, literature, or life
4. **What next?** — WhatNext block, **max 3 actions**

**3-3-3 Rule:** a student grasps *what this is* in 3 minutes; the essential concepts sit in the first 3 sections; the page ends with ≤3 actions.

## 3. Per-type structures
- **Literature guide:** section order fixed — Overview → Historical Background → Author → Summary → Themes → Characters → Symbolism → Motifs → Literary Devices → Important Quotes → Exam Questions → Critical Interpretations → Discussion Questions → Vocabulary → Timeline → Further Reading. Omit sections that don't apply; never reorder.
- **Weekly module:** Read before class → Lecture notes → Tutorial discussion question (exactly one) → Revision pointers.
- **CEFR lesson:** Can-do statement first, then teach, then a self-check ("What can I do now?").
- **AI article:** dated; state model/tool versions; flag anything likely to age in a "Currency note".
- **Academic Success guide:** worked example mandatory (a real, anonymised student-style excerpt improved step by step).

## 4. Citations & referencing
- Public-domain quotations: cite work + line/chapter inline, e.g. *(Ozymandias, l. 11)*.
- Scholarship: Harvard author–date in text, References list at page end.
- **Never invent citations.** Quote only text present in the guide's source material.
- Copyright: only public-domain or licensed full texts; otherwise excerpt within fair-dealing limits.

## 5. Images, diagrams, tables
- Diagrams over decoration; every image needs descriptive alt text.
- Tables for enumerable facts only (≤ 6 columns); explanation lives in prose.
- SVG preferred; photos via Next/Image with width/height set (no CLS).

## 6. Accessibility
- One `h1` per page; heading levels never skip.
- Colour never the sole carrier of meaning (theme tags carry labels).
- Contrast ≥ WCAG AA; all interactive elements keyboard-reachable; quiz components announce results to screen readers.

## 7. Internal linking
- Every page links ≥ 2 related pages (frontmatter `related[]`) — the knowledge web is a feature, not an afterthought.
- Link text descriptive ("guide to *Ozymandias*", never "click here").
- Cross-pillar links encouraged (poem guide → CEFR vocabulary lesson → academic-success essay guide).

## 8. Metadata & SEO
- Unique `<title>` (≤ 60 chars) and meta description (≤ 155 chars) per page.
- Open Graph: title, description, cover (poster image for articles; generated card for guides).
- Frontmatter `updated` refreshed on every meaningful edit — it drives Recently Updated.

## 9. Pre-publication checklist (Content Quality Standard)
✓ explains clearly ✓ examples included ✓ diagrams where apt ✓ further reading ✓ ≥2 related links ✓ consistent terminology ✓ mobile-checked ✓ appears in search index ✓ fact-checked ✓ metadata current ✓ Four-Question Framework satisfied ✓ UK English pass

## 10. AI-assisted drafting rule
AI may draft; Dr. Basha reviews and approves every page before merge. The private Lecturer Note in JB COG OS records classroom observations that feed the next revision. AI-drafted text must never contain invented quotations, invented citations, or claims about the set texts not verifiable in the source material.
