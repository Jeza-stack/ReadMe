# ReadMe Editorial Calendar

A publishing rhythm, not code. Turns ReadMe from a website into a living academic publication. Adjust freely to the teaching term; the point is a steady cadence, not rigid dates.

## Weekly cadence (suggested)
- **Monday** — one Literature Guide improved or added (English I–IV works)
- **Wednesday** — one CEFR lesson (start with B1 academy)
- **Friday** — one AI for Students article
- **Weekend** — one Academic Success or Soft Skills guide

## Development phase — this is now the loop
```
Teach → Observe students → Record notes (JB COG OS Lecturer Notes) → Improve guide → Publish
```
Students are the primary source of improvements. Each semester's teaching feedback feeds the next revision (Lecturer Notes loop, Master Design Spec).

## Pillar population priority (JB-approved order)
1. CEFR English (complements teaching, broadens audience) — B1 academy first
2. Academic Success (immediately useful to students)
3. AI for Students (distinctive, regularly updated)
4. Soft Skills (employability)
5. IQ Test / Cognitive Assessment (valuable, least tied to semester rhythm)

## Publishing checklist per piece
Content Style Guide pre-publication checklist + Four-Question Framework + copyright status set (literature) + `updated` date current → `npm run build` green → commit → push.
